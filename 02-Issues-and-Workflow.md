# 📘 Issues & Workflow in JIRA

## What is an Issue?

An Issue represents a task, bug, story, or work item.

---

## Types of Issues

- Story
- Task
- Bug
- Epic
- Sub-task

---

## Workflow

Workflow defines the lifecycle of an issue.

Example:

To Do → In Progress → Review → Done

---

## Status

Each issue has a status:

- To Do
- In Progress
- Done
